# Elasticsearch

## 掌握程度

能够进行基础 mapping 设计、中文分词、全文检索、过滤和排序，理解搜索索引与业务数据库之间通常是最终一致。没有大型 Elasticsearch 集群运维经验。

## 实际使用

在“校园二手交易小程序”中为商品标题、描述和分类建立索引，价格、发布时间和商品状态用于过滤或排序。PostgreSQL 保持为事实源。

## 解决的问题

针对短时间连续修改造成的乱序覆盖，在同步任务和索引文档中加入商品版本号，旧版本任务不再覆盖新文档，并提供按商品 ID 重建索引的恢复接口。

## 复盘

课程项目没有千万级数据和生产性能指标，也没有分片迁移、冷热架构或集群容量规划经验。
