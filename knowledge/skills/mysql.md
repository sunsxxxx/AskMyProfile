# MySQL

## 掌握程度

能够进行表结构设计、索引设计、事务使用和常见慢 SQL 排查，理解 B+Tree、联合索引最左前缀、MVCC 和常见隔离级别。没有数据库内核开发经验。

## 实际使用

在“智能仓储协同平台”中设计库存表、库存流水表、调拨单和 outbox 表。以仓库 ID 与 SKU ID 建联合唯一索引，通过带库存条件的 `UPDATE` 和受影响行数判断扣减结果。

## 解决的问题

用唯一索引兜底业务幂等；通过 `EXPLAIN`、慢查询日志和实际查询条件检查索引是否有效。事务只覆盖必要的数据库操作，网络调用放在事务外，避免长期占用连接。

## 复盘

使用过主键、唯一索引和普通联合索引，但没有分库分表落地经验，也没有管理 MySQL 主从切换的经历。
