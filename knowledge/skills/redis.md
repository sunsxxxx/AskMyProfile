# Redis

## 掌握程度

熟悉 String、Hash、Set、ZSet、过期策略、Cache Aside、Lua 原子操作和常见缓存一致性问题；有向量索引、限流、幂等和热点缓存的项目使用经验。没有 Redis Cluster 生产运维经验。

## 实际使用

在“智能仓储协同平台”中，Redis 用于热点库存查询和调拨请求幂等，但库存扣减仍以 MySQL 条件更新为准。在“技术面试问答助手”中，Redis 分别用于 Vector Search、LangGraph checkpoint、Lua 滑动窗口限流和 GitHub API 缓存。

## 解决的问题

能够针对缓存穿透设置空值短 TTL，针对雪崩给 TTL 增加随机抖动，并把数据库作为事实源。对删除缓存失败，使用事务后事件、重试表和监控补偿，而不是承诺绝对强一致。

## 取舍

不会在所有并发场景默认使用分布式锁。仓储项目的库存扣减使用数据库条件更新，避免锁续期、主从切换和故障恢复带来的复杂度。

## 复盘

了解主从、哨兵和 Cluster 的基本原理，但现有资料中没有亲自维护生产 Redis Cluster 或处理大规模集群故障的记录。
