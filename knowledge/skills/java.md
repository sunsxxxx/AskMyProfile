# Java

## 掌握程度

能够使用 Java 17 和 Spring Boot 完成常见后端模块，理解集合、异常、泛型、线程池、JVM 内存区域和基础 GC 日志。不会把掌握程度描述为“精通 JVM”。

## 实际使用

在“智能仓储协同平台”中使用 Java 17、Spring Boot 3 和 MyBatis-Plus 开发库存与调拨模块，编写事务边界、参数校验、统一异常处理和集成测试。

## 并发经验

对库存扣减优先使用数据库条件更新保证原子性；异步任务使用有界线程池，并显式配置队列容量和拒绝策略。没有自行实现锁框架。

## 复盘

能够借助线程 dump 和指标排查线程池阻塞，但没有生产环境大规模 JVM 调优经历。
